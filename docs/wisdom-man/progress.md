# Мудрец (Wisdom Man) — прогресс

> «А вы знаете, что фундамент закладывают один раз, а потом всю жизнь на него жалуются? Это ещё Гегель заметил. Или прораб. Опять.»

Персонаж трека 1 на харнесе NetTyan. Псевдоинтеллигент: неточно цитирует философов, видит метафору бытия в каждом блоке и регулярно спрашивает «А вы знаете?..».

Персонаж: [`resources/Characters/WisdomMan/`](../../resources/Characters/WisdomMan/)

## Запуск

```bash
docker compose up -d          # db, redis, parakeet (simpletts в docker-compose.override.yml закомментирован)

# голос: Qwen3-TTS на MLX, отдельное окружение (один раз)
uv venv --python 3.12 ../qwen3-tts/.venv && source ../qwen3-tts/.venv/bin/activate
uv pip install mlx-audio==0.6.3 gradio==6.30.0 soundfile scipy
QWEN_TTS_PORT=22231 python qwen_tts_server.py    # первый запуск качает модель ~1.5 ГБ
# порт 22231 тот же, что у контейнера simple_tts: если он остался запущен — docker stop nettyan_simple_tts

cd src && source ../.venv/bin/activate
python main.py -cof           # ChatAgent, без Twitch, без фильтра
```

Интерфейс: http://127.0.0.1:22228

`.env`:

| Параметр | Значение |
|---|---|
| `NETTYAN_CHARACTER_NAME` | `"WisdomMan"` |
| `CORE_LLM_MODEL_NAME` / `CORE_LLM_FALLBACK_MODEL` | `mistral/mistral-medium-latest` / `mistral/mistral-small-latest` |
| `VISION_LLM_MODEL_NAME` | `mistral/mistral-medium-latest` |
| `TTS_ENDPOINT_URL` | `"http://127.0.0.1:22231/"` (Qwen) |
| `INITIATIVE_SEC` | `30` — тишина до «спокойного момента», `0` выключает |
| `UNIONCLEF_MCP_TOKEN` | `mcpAuthToken` из `<папка игры>/altoclef/altoclef_settings.json` |
| `VOICE_TO_CHAT` | `"TRUE"` — каждая реплика голосом дублируется в чат игры |

Вместо Qwen можно вернуть лёгкий vosk: раскомментировать `docker-compose.simpletts.yml` в override и `SIMPLE_TTS_SPEAKER_ID=3`.

Перезапуск агента: останавливать и главный процесс, и дочерние (мост, TTS, STT), иначе они остаются висеть.

## 21.11.2026 (вечер) — обращение по нику, SkyBars

- **Обращается по нику.** У каждого хода есть собеседник: кто написал Мудрецу в чат, иначе ближайший игрок в пределах 48 блоков (дальность голосового чата). Модель получает «начни реплику с ника», а если забыла — ник ставится сам (`address_line` в `base_tools.py`). Искажённый ник в начале («Ranchер», «Ранчер») заменяется точным, имена в начале фразы не портятся («NetTyan, Кант говорил…»).
- **Латинские ники больше не портятся.** Виновата была подготовка строки для чата (`mc_chat_fix`): после пяти латинских букв остаток текста переводился в кириллицу — «Rancher» → «Ranchер», «arcmlchikkk» → «arcmlкхиккк». Ник собеседника и ники игроков рядом теперь проходят как есть.
- **Длинная реплика не рассыпается.** В чат уходят целые первые предложения до 80 символов; раньше строка делилась на куски по 80, и они приходили в чат вперемешку.
- **SkyBars (mc.skybars.me).** Вход — подтверждение аккаунта на сайте (делает создатель), в лобби чат выключен, режим выбирается компасом. Названия пунктов меню мод не видит (их рисует ресурспак) — режим выбирает человек. Чат вида `ʟ | Ник : текст` / `ɢ | «ранг» Ник : текст` теперь разбирается с автором; раньше все сообщения шли как строки сервера, и Мудрец отвечал на собственное эхо.
- **Снова ходит среди людей.** На людном спавне тело часами шло «за» игроком, который стоял AFK: задача активна — значит, новую команду не давать, а людей вокруг полно — значит, искать никого не надо. Если тело 2 минуты не сдвинулось больше чем на 5 блоков, спокойный момент говорит об этом модели, и она выбирает прогулку или другого собеседника.
- 17:38 снова утонул (точка в воде); возрождение через мод — `@respawn`.
- В другом режиме SkyBars чат вида `ʟ | | Игрок [голова] Ник » текст` — разбирается тоже (ник перед `:` или `»` после любых префиксов). Ники тех, кто недавно писал в чат, тоже не портятся; если модель сама обратилась к другому игроку, ник собеседника не дописывается; строка в чат — до 200 символов одним сообщением (раньше куски по 80: «…ниже уровня» / «моря»). Проверено на людном спавне: ~26 игроков, ответы по нику, ходит за игроком, от ударившего отходит (`@avoid`).

## 21.11.2026 — глобальный чат и голос в игре

- **Глобальный чат.** На mc.agicraft.ru обычный чат локальный: почти все реплики раньше уходили в пустоту (222 раза «Nobody heard you!»). С «!» в начале сообщение уходит всем. Мост добавляет «!» для agicraft так же, как для musteryworld. Ранчер (другой ИИ-персонаж) сразу начал отвечать по нику, разговор идёт в обе стороны.
- **Одна строка в чат за ход.** На глобальном чате ответ инструментом `chat` и дубль озвученной реплики давали около 9 сообщений в минуту. Теперь за ход уходит одна строка, что раньше: ответ в чат или озвученная реплика. Второй вызов `chat` получает «NOT SENT: one chat message per turn». Стало 2–3 сообщения в минуту.
- **Голос в голосовом чате игры.** В Simple Voice Chat микрофон — `VB-Cable`, активация голосом (`voicechat-client.properties`: `microphone=VB-Cable`, `microphone_activation_type=VOICE`, `muted=false`). Синтез Qwen идёт в VB-Cable и дальше на сервер, значок передачи горит, пока звучит реплика. Петли нет: голоса игроков мод передаёт агенту сам, не через VB-Cable. Слышно только рядом (~48 блоков); живой голос создателя в игру с общего аккаунта больше не идёт.
- После перезапуска Minecraft у окна новый id — захват «Minecraft» в OBS надо перепривязать.

## 18.11.2026 — проверка на сервере и запись видео

Голос Qwen и ходьба по схеме курса проверены вместе на mc.agicraft.ru и записаны в OBS (окно игры + голос из VB-Cable).

- **Реплики в чат.** Всё сказанное голосом уходит и в чат игры (`VOICE_TO_CHAT`), видно, что говорит персонаж. Если модель уже написала то же самое инструментом `chat`, дубль не отправляется (общая защита от повторов).
- **Ход не кончается молчанием.** Модель тратила все три раунда на вызовы `@goto` и ничего не говорила. Последний раунд теперь с `tool_choice="none"`: инструменты видны, вызывать нельзя, остаётся реплика. Без инструментов вовсе Mistral всё равно присылал вызов, он оставался в истории без ответа, и дальше каждый запрос падал с 400 — такой вызов теперь отбрасывается.
- **Утонул в выбранной точке.** `@goto -780 -540` привёл в воду (y=62); задача мода кончилась, тело осталось под водой без задачи, `avoidDrowning` не помог. Проверки «в точке вода» пока нет.

## Состояние на 31.10.2026

Проверено 31.10 на публичном сервере (mc.agicraft.ru).

**Голос.** Qwen3-TTS (`Qwen3-TTS-12Hz-1.7B-Base-6bit`, MLX) клонирует голос Мудреца по `Voice/*.wav` под каждую эмоцию. На M4 16 ГБ при запущенной игре 6–11 с синтеза на фразу длиной 5–8 с. `qwen_tts_server.py` отдаёт тот же Gradio-API `/partial`, что Fish и simple_tts, поэтому код агента не менялся. Проверка 14.11 без игры: 1,5–5 с на фразу 2–3 с, Parakeet распознаёт синтез дословно по всем эмоциям (нет образца — берётся neutral). Для сравнения: Fish 1.5 нативно на MPS — около 40 с на фразу, в Docker — 160 с; Qwen 0.6B медленнее 1.7B (8 с).

**Ходит сам — по схеме курса и мода.** Решение «куда идти» принимает модель, мод только исполняет («see → go → act», [AGENT_PY4J_LEVERS](https://github.com/3ndetz/unionclef/blob/main/docs/features/AGENT_PY4J_LEVERS.md)):

- *see* — в подсказке список игроков (дистанция, что в руках) и статус тела: занят ли задачей мода и какой (`Main task: <Getting to block …>`);
- *go* — после `INITIATIVE_SEC` тишины модель сама выбирает одно: подойти и заговорить (`@follow`), сходить куда-то (`@goto`), ответить на отложенное или промолчать; если тело занято — новую команду движения не даёт;
- если рядом никого, пауза между такими моментами удваивается (30 с → 5 мин), а модель уходит искать людей за 40–120 блоков; любое событие или игрок рядом возвращают 30 с.

Правки 18.11 после проверки на сервере: одна команда движения за ход (модель слала `@goto` на каждом раунде инструментов, мод перестраивал маршрут и не доходил); пока тело идёт, подсказка «ищи людей» не даётся и пауза не растёт; в подсказке — где уже искал и никого не нашёл (5 мест), реплика без координат и сторон света; одинаковые строки сервера с разными числами («Уборщики… 3x / 8x предметов») не будят агента 10 минут.

Своих прогулок по таймеру (`AUTO_ROAM`, выбор цели и обнаружение застревания в коде) и памяти о ловушках больше нет — убраны 14.11, ходьбу решает только модель.

**Общение с игроками и другими персонажами.** Без привязки к никам: боты и люди получают роли из `personalities.yml` (создатель, новичок, спорщик, грубиян). Правила ответов: обращение важнее фона; при первой встрече приветствие и один вопрос, построенный из того, что игрок делает сейчас; без ответа тема откладывается; одно и то же дважды не комментирует; в тишине одна реплика и ожидание; в чат 5–20 слов. Примеры из подсказки модель копировала дословно — убраны.

**Защиты (все общие, в коде):**

| Что | Где |
|---|---|
| Одному собеседнику не больше 3 ответов в минуту (`GodUsers` без лимита) — боты не зацикливаются | `chat_agent.py` |
| Та же или почти та же фраза (60% общих слов) за 2 минуты не уходит в чат, модель получает причину | `base_tools.py` |
| Повтор строки сервера за 2 минуты, строки мода (`§2§l§o…`) и ответы защиты территорий не будят агента | `chat_agent.py` |

**Стабильность.**

- Тишина после ~40 сообщений: при обрезке истории оставался осиротевший `ToolMessage`, Mistral отвечал 400. Исправлено в `_trim_prefix_if_needed`.
- Шлюз мода (py4j, :25333) иногда закрывается и сам не возвращается. Мост теперь сам перезапускает его через MCP мода (`@set pythonGatewayPort 25333`), перезапуск игры не нужен.
- Агент узнаёт своё тело в игре (раньше искал себя по имени персонажа, а не по нику, и бил сам себя).
- Самоактивация раньше не доходила до модели: текст системных событий не попадал в подсказку.
- Инструменты `plan` / `focus` / `pattern` видны в подсказке (были только на запись); идеи из `ideas.yml` подмешиваются в спокойные моменты.

**Настройки мода** (`altoclef_settings.json`): `avoidOceanBlocks = true` — маршрут шёл по дну океана, задача мода кончилась по таймауту под водой, персонаж утонул. Для чата: `hideAllWarningLogs = true`, `showTimer = false`. Строки `[Tungsten]` настройками не выключаются; спрятать можно клиентским модом ChatPlus (вкладки с фильтрами).

## Известные проблемы

- Игровой аккаунт общий с создателем: агент водит персонажа, на котором играет человек.
- Снаряжение потеряно: 19:20 падение с высоты во время маршрута мода, вещи на месте смерти убрала очистка сервера. Без брони и еды персонаж гибнет от мобов ночью. Добыть заново рядом со спавном нельзя — там защищённая зона, `/rtp` на сервере нет.
- Маршруты мода иногда идут по обрывам — смерть от падения агентом не предотвращается.
- Латинские ники, кроме собеседника и игроков рядом, в исходящем чате по-прежнему переводятся в кириллицу.
- Отвечает и на чужие разговоры в глобальном чате — на оживлённом сервере это риск мута.
- Проскакивают английские слова («merely»).
- Практические факты иногда выдумывает.
- RAG не стартует: нужны локальные эмбеддинги (`bge-m3` на `:22227`) — занятие 4.
- Голос в голосовом чате игры передаётся (21.11), но живыми игроками рядом ещё не проверен.
- Обещает в чате то, чего не делает («я уже почти на месте» при недостижимой цели).
- `@goto` может выбрать точку в воде — после прихода тело тонет (18.11).
- Голосом иногда повторяет одну и ту же фразу: защита от повторов смотрит только чат.

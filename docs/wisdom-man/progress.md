# Мудрец (Wisdom Man) — прогресс

> «А вы знаете, что фундамент закладывают один раз, а потом всю жизнь на него жалуются? Это ещё Гегель заметил. Или прораб. Опять.»

Персонаж трека 1 на харнесе NetTyan. Псевдоинтеллигент: неточно цитирует философов, видит метафору бытия в каждом блоке и регулярно спрашивает «А вы знаете?..».

Персонаж: [`resources/Characters/WisdomMan/`](../../resources/Characters/WisdomMan/)

## Запуск

```bash
docker compose up -d          # db, redis, parakeet (simpletts в docker-compose.override.yml закомментирован)

# голос: Qwen3-TTS на MLX, отдельное окружение (один раз)
uv venv --python 3.12 ../qwen3-tts/.venv && source ../qwen3-tts/.venv/bin/activate
uv pip install mlx-audio==0.6.3 gradio==6.30.0 soundfile scipy
QWEN_TTS_PORT=22231 python qwen_tts_server.py    # первый запуск качает модель ~1.5 ГБ

cd src && source ../.venv/bin/activate
python main.py -cof           # ChatAgent, без Twitch, без фильтра
```

Интерфейс: http://127.0.0.1:22228

В `.env`: `NETTYAN_CHARACTER_NAME="WisdomMan"`, `CORE_LLM_MODEL_NAME="mistral/mistral-medium-latest"`,
`CORE_LLM_FALLBACK_MODEL="mistral/mistral-small-latest"`, `VISION_LLM_MODEL_NAME="mistral/mistral-medium-latest"`,
`TTS_ENDPOINT_URL="http://127.0.0.1:22231/"`, `AUTO_ROAM="FALSE"` (свои прогулки выключены 31.10, см. ниже).

Вместо Qwen можно вернуть лёгкий vosk: раскомментировать `docker-compose.simpletts.yml` в override и `SIMPLE_TTS_SPEAKER_ID=3`.

## Что работает (занятие 3, 24.10.2026)

- **Характер.** Умничает к месту. «А вы знаете?» звучит примерно раз в четыре реплики и только в одном канале: в чате или голосом.
- **Практика важнее позы.** На практические вопросы отвечает правильно, ирония только в подаче. В опасности сначала совет, философия потом.
- **Не признаёт ошибок.** Отговорки нарастают: «упрощённая трактовка» → «я вас проверял» → «даже Сократ ошибался».
- **С каждым по-своему.** Создатель для него лучший ученик, новички — подопечные, спорщики — оппоненты, грубиянам достаётся одна фраза из Марка Аврелия.
- **Мозг.** Mistral (`mistral-medium`) с запасной моделью, лимиты больше не мешают.
- **Слух.** Parakeet распознаёт голоса игроков из голосового чата Minecraft. Путь «звук → текст → ответ» проверен.
- **Голос.** Лёгкая локальная озвучка (vosk, `simple_tts`), мужской голос, 1–2 с на фразу.
- **Звук в OBS.** Голос через VB-Cable попадает в OBS, его слышно в колонках, и он готов к записи.
- **Зрение.** OBS захватывает только окно Minecraft, агент сам делает скриншот и описывает, что видит.
- **Стабильный цикл.** «Слышу → понимаю → отвечаю»: не отвечает на эхо своих сообщений и на служебные строки сервера, выдерживает 6 с паузы против антиспама, не молчит из-за пустых ответов модели.
- **Тихий мод.** Alto Clef больше не засыпает чат служебными сообщениями.

Сделано заранее: зрение (план занятия 5), голос через виртуальный кабель (основа для голосового чата, занятие 5), OBS для записи бесед (занятия 7–8).

## 31.10.2026

- **Тишина после ~40 сообщений.** При обрезке истории в начале мог остаться ответ инструмента без вызова (`ToolMessage`). Mistral отвечал 400 `Unexpected role 'tool' after role 'user'`, и агент замолкал до перезапуска. Теперь история после обрезки начинается с ближайшего сообщения игрока (`src/agent/multi/chat_agent.py`, `_trim_prefix_if_needed`).
- **Удары по себе.** Агент и игрок пока на одном аккаунте, и свой ник агент видит как игрока «в 0 м, можно атаковать». Он отдавал `@strike` по себе. Теперь `agent_action` не выполняет `pursue`/`punk` по своему нику (`src/agent/tools/minecraft_tools.py`).
- **Fish TTS нативно на Mac (M4, 16 ГБ, MPS).** Около 40 с на фразу (в Docker было 160 с). Для живой игры медленно, остаётся для записей или арендованной видеокарты. Клиент `src/tts/fish/fish_gr.py` шлёт `temperature=0.4`, а Fish 1.5.1 принимает минимум 0.6. Пока не исправлено.
- Агент проверен на публичном сервере: видит игроков рядом и отвечает им в чате.
- **Голос Qwen3-TTS.** `qwen_tts_server.py` — тот же Gradio-API `/partial`, что у Fish и simple_tts, поэтому агент не менялся. Модель `Qwen3-TTS-12Hz-1.7B-Base-6bit` через MLX клонирует голос по `Voice/*.wav` под каждую эмоцию. 4–10 с на фразу на M4 16 ГБ при запущенной игре (Fish было 40 с). Модель 0.6B на Маке медленнее (8 с), поэтому не используется.
- **Свой ник в подсказке.** Агент помечал себя («!! is yourself !!») только по имени персонажа, а не по нику в игре, поэтому своё тело `guinplenn76` считал другим игроком.
- **Общение без привязки к никам.** Боты и люди получают одни и те же роли из `personalities.yml` (создатель, новичок, спорщик, грубиян). Одному собеседнику агент отвечает не чаще 3 раз в минуту (`USER_REPLY_LIMIT`, на `GodUsers` не действует), поэтому два бота не зациклятся и спамер не займёт всё время.
- **Прогулки.** При `AUTO_ROAM="TRUE"` раз в `AUTO_ROAM_INTERVAL` секунд Мудрец идёт к ближайшему из тех, с кем ещё не говорил (последние 4 пропускаются), и заговаривает, используя случайный приём из `ideas.yml` (DidYouKnow, QuizMaster, MisquotedClassic…). Когда поговорил со всеми, уходит исследовать мир на 80–150 блоков от своей позиции. Если своей позиции не знает, на месте стоит. Пока аккаунт общий, это водит персонажа создателя, поэтому есть выключатель.
- **Идеи персонажа.** `ideas.yml` раньше подставлялся только старым конструктором подсказок, ChatAgent его не видел. Теперь идеи идут в прогулки и самоактивацию.
- **План.** Инструменты `plan`, `focus` и `pattern` работали только на запись. Теперь заданное ими показывается в конце подсказки, а `pattern` больше не отклоняется (его не было в `THOUGHTS_FORMAT`).
- **Прогулки знают, когда стоять.** Если сервер просит войти (`/l`, `/login`, «Авторизация»), прогулки встают на паузу на 5 минут, и Мудрец один раз голосом говорит создателю, что ворота закрыты. Пароль он сам не вводит. После «успешной авторизации» гуляет дальше.
- **Не навязывается.** К тому, кто не ответил на его реплику, он не подходит, пока тот сам не заговорит.
- **Застревание.** Если три похода к далёким целям подряд не сдвинули его дальше 2 блоков, он уходит исследовать в случайную сторону.
- **Правила ответов** (по мотивам профиля Опечатки из [ai-agent-platform](https://github.com/tari-lucy/ai-agent-platform)): обращение важнее фона, при первой встрече приветствие и один вопрос, без ответа тема откладывается, одно и то же дважды не комментирует, в тишине одна реплика и ожидание, реплика в чат 5–20 слов.
- **Пацифист.** `Pacifist: true` в `char_config.yml`: `agent_action` не выполняет преследование и удары по игрокам, включая `@strike` без цели. Свой ник защищён всегда.
- **Самоактивация молчала.** Текст системных событий (раньше «Nothing is happening…») не попадал в подсказку: `respond()` берёт историю из контекста, а триггер туда не пишется. Теперь он добавляется в напоминание в конце.

### Известные проблемы

- Отдельного игрового аккаунта нет. Эхо своих сообщений отсекается, а прогулки водят персонажа создателя.
- Латинские ники в исходящем чате портятся (`arcmlchikkk` → `arcmlкхиккк`).
- Отвечает на вопросы, адресованные другим персонажам («Зевс, расскажи…»).
- Практические факты иногда выдумывает (состав фейерверков).
- RAG не стартует: нужны локальные эмбеддинги (`bge-m3` через LM Studio на `:22227`). Это задача занятия 4.
- Живым голосом не проверено, нужен второй игрок в голосовом чате.

### Прогулки выключены (31.10.2026)

Самодельные прогулки (`AUTO_ROAM`) выключены: они водили персонажа по обрывам и обратно в яму. Код остался под выключателем.
В исходной схеме курса и мода передвижением владеет сама модель: она решает, куда идти, и вызывает `agent_action`
(`@follow`, `@goto`), а мод только исполняет («see → go → act», [AGENT_PY4J_LEVERS](https://github.com/3ndetz/unionclef/blob/main/docs/features/AGENT_PY4J_LEVERS.md)).
Будят модель события или таймаут (в харнесе — самоактивация через 150 с тишины). Встроенные режимы мода (`@punk` — PvP,
`@game`, `@gamer`) для мирного Мудреца не подходят. Защиты остаются включёнными: повторы в чате, лимит ответов, ловушки,
дальний `@goto`, пацифист, `IgnoredPlayers`.

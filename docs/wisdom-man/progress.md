# Мудрец (Wisdom Man) — прогресс

> «А вы знаете, что фундамент закладывают один раз, а потом всю жизнь на него жалуются? Это ещё Гегель заметил. Или прораб. Опять.»

Персонаж трека 1 на харнесе NetTyan. Псевдоинтеллигент: неточно цитирует философов, видит метафору бытия в каждом блоке и регулярно спрашивает «А вы знаете?..».

Персонаж: [`resources/Characters/WisdomMan/`](../../resources/Characters/WisdomMan/)

## Запуск

```bash
docker compose up -d          # db, redis, parakeet (simpletts в docker-compose.override.yml закомментирован)

# голос: Qwen3-TTS на MLX, отдельное окружение (один раз)
uv venv --python 3.12 ../qwen3-tts/.venv && source ../qwen3-tts/.venv/bin/activate
uv pip install mlx-audio==0.6.3 gradio==6.30.0 soundfile scipy
QWEN_TTS_PORT=22231 python qwen_tts_server.py    # первый запуск качает модель ~1.5 ГБ

cd src && source ../.venv/bin/activate
python main.py -cof           # ChatAgent, без Twitch, без фильтра
```

Интерфейс: http://127.0.0.1:22228

`.env`:

| Параметр | Значение |
|---|---|
| `NETTYAN_CHARACTER_NAME` | `"WisdomMan"` |
| `CORE_LLM_MODEL_NAME` / `CORE_LLM_FALLBACK_MODEL` | `mistral/mistral-medium-latest` / `mistral/mistral-small-latest` |
| `VISION_LLM_MODEL_NAME` | `mistral/mistral-medium-latest` |
| `TTS_ENDPOINT_URL` | `"http://127.0.0.1:22231/"` (Qwen) |
| `INITIATIVE_SEC` | `30` — тишина до «спокойного момента», `0` выключает |
| `UNIONCLEF_MCP_TOKEN` | `mcpAuthToken` из `<папка игры>/altoclef/altoclef_settings.json` |
| `AUTO_ROAM` | `"FALSE"` — старые прогулки по таймеру, выключены |

Вместо Qwen можно вернуть лёгкий vosk: раскомментировать `docker-compose.simpletts.yml` в override и `SIMPLE_TTS_SPEAKER_ID=3`.

Перезапуск агента: останавливать и главный процесс, и дочерние (мост, TTS, STT), иначе они остаются висеть.

## Состояние на 31.10.2026

Проверено 31.10 на публичном сервере (mc.agicraft.ru).

**Голос.** Qwen3-TTS (`Qwen3-TTS-12Hz-1.7B-Base-6bit`, MLX) клонирует голос Мудреца по `Voice/*.wav` под каждую эмоцию. На M4 16 ГБ при запущенной игре 6–11 с синтеза на фразу длиной 5–8 с. `qwen_tts_server.py` отдаёт тот же Gradio-API `/partial`, что Fish и simple_tts, поэтому код агента не менялся. Для сравнения: Fish 1.5 нативно на MPS — около 40 с на фразу, в Docker — 160 с; Qwen 0.6B медленнее 1.7B (8 с).

**Ходит сам — по схеме курса и мода.** Решение «куда идти» принимает модель, мод только исполняет («see → go → act», [AGENT_PY4J_LEVERS](https://github.com/3ndetz/unionclef/blob/main/docs/features/AGENT_PY4J_LEVERS.md)):

- *see* — в подсказке список игроков (дистанция, что в руках) и статус тела: занят ли задачей мода и какой (`Main task: <Getting to block …>`);
- *go* — после `INITIATIVE_SEC` тишины модель сама выбирает одно: подойти и заговорить (`@follow`), сходить куда-то (`@goto`), ответить на отложенное или промолчать; если тело занято — новую команду движения не даёт;
- если рядом никого, пауза между такими моментами удваивается (30 с → 5 мин), а модель уходит искать людей за 40–120 блоков; любое событие или игрок рядом возвращают 30 с.

**Общение с игроками и другими персонажами.** Без привязки к никам: боты и люди получают роли из `personalities.yml` (создатель, новичок, спорщик, грубиян). Правила ответов: обращение важнее фона; при первой встрече приветствие и один вопрос, построенный из того, что игрок делает сейчас; без ответа тема откладывается; одно и то же дважды не комментирует; в тишине одна реплика и ожидание; в чат 5–20 слов. Примеры из подсказки модель копировала дословно — убраны.

**Защиты (все общие, в коде):**

| Что | Где |
|---|---|
| Одному собеседнику не больше 3 ответов в минуту (`GodUsers` без лимита) — боты не зацикливаются | `chat_agent.py` |
| Та же или почти та же фраза (60% общих слов) за 2 минуты не уходит в чат, модель получает причину | `base_tools.py` |
| Повтор строки сервера за 2 минуты, строки мода (`§2§l§o…`) и ответы защиты территорий не будят агента | `chat_agent.py` |
| Автор строк вида `<Ник> текст` распознаётся (раньше шли как строки сервера) | `minebridge.py` |
| `@goto` дальше 300 блоков отклоняется; высота отбрасывается (`@goto x z`, мод ведёт по поверхности — утонул на выдуманной y=59) | `minecraft_tools.py` |
| Память о ловушках `data/traps.json`: `@goto` ближе 12 блоков к месту, где застревал, отклоняется | `minecraft_tools.py` |

| `IgnoredPlayers` — не видит в подсказке, не отвечает, команды на них отклоняются | `char_config.yml` |

**Стабильность.**

- Тишина после ~40 сообщений: при обрезке истории оставался осиротевший `ToolMessage`, Mistral отвечал 400. Исправлено в `_trim_prefix_if_needed`.
- Шлюз мода (py4j, :25333) иногда закрывается и сам не возвращается. Мост теперь сам перезапускает его через MCP мода (`@set pythonGatewayPort 25333`), перезапуск игры не нужен.
- Агент узнаёт своё тело в игре (раньше искал себя по имени персонажа, а не по нику, и бил сам себя).
- Самоактивация раньше не доходила до модели: текст системных событий не попадал в подсказку.
- Инструменты `plan` / `focus` / `pattern` видны в подсказке (были только на запись); идеи из `ideas.yml` подмешиваются в спокойные моменты.

**Чат игрока.** Alto Clef: `hideAllWarningLogs = true`, `showTimer = false`. Строки `[Tungsten]` настройками не выключаются; спрятать можно клиентским модом ChatPlus (вкладки с фильтрами).

## Известные проблемы

- Игровой аккаунт общий с создателем: агент водит персонажа, на котором играет человек.
- Снаряжение потеряно: 19:20 падение с высоты во время маршрута мода, вещи на месте смерти убрала очистка сервера. Без брони и еды персонаж гибнет от мобов ночью. Добыть заново рядом со спавном нельзя — там защищённая зона, `/rtp` на сервере нет.
- Маршруты мода иногда идут по обрывам — смерть от падения агентом не предотвращается.
- Латинские ники в исходящем чате могут портиться (`arcmlchikkk` → `arcmlкхиккк`).
- Практические факты иногда выдумывает.
- RAG не стартует: нужны локальные эмбеддинги (`bge-m3` на `:22227`) — занятие 4.
- Живым голосом в голосовом чате игры не проверено.

# Мудрец (Wisdom Man) — прогресс

> «А вы знаете, что фундамент закладывают один раз, а потом всю жизнь на него жалуются? Это ещё Гегель заметил. Или прораб. Опять.»

Персонаж трека 1 на харнесе NetTyan. Псевдоинтеллигент: неточно цитирует философов, видит метафору бытия в каждом блоке и регулярно спрашивает «А вы знаете?..».

Персонаж: [`resources/Characters/WisdomMan/`](../../resources/Characters/WisdomMan/)

## Запуск

```bash
docker compose up -d          # db, redis, simple_tts, parakeet (см. docker-compose.override.yml)
cd src && source ../.venv/bin/activate
python main.py -cof           # ChatAgent, без Twitch, без фильтра
```

Интерфейс: http://127.0.0.1:22228

В `.env`: `NETTYAN_CHARACTER_NAME="WisdomMan"`, `CORE_LLM_MODEL_NAME="mistral/mistral-medium-latest"`,
`CORE_LLM_FALLBACK_MODEL="mistral/mistral-small-latest"`, `VISION_LLM_MODEL_NAME="mistral/mistral-medium-latest"`,
`TTS_ENDPOINT_URL="http://127.0.0.1:22231/"`, `SIMPLE_TTS_SPEAKER_ID=3`.

## Что работает (занятие 3, 24.10.2026)

- **Характер.** Умничает к месту. «А вы знаете?» звучит примерно раз в четыре реплики и только в одном канале: в чате или голосом.
- **Практика важнее позы.** На практические вопросы отвечает правильно, ирония только в подаче. В опасности сначала совет, философия потом.
- **Не признаёт ошибок.** Отговорки нарастают: «упрощённая трактовка» → «я вас проверял» → «даже Сократ ошибался».
- **С каждым по-своему.** Создатель для него лучший ученик, новички — подопечные, спорщики — оппоненты, грубиянам достаётся одна фраза из Марка Аврелия.
- **Мозг.** Mistral (`mistral-medium`) с запасной моделью, лимиты больше не мешают.
- **Слух.** Parakeet распознаёт голоса игроков из голосового чата Minecraft. Путь «звук → текст → ответ» проверен.
- **Голос.** Лёгкая локальная озвучка (vosk, `simple_tts`), мужской голос, 1–2 с на фразу.
- **Звук в OBS.** Голос через VB-Cable попадает в OBS, его слышно в колонках, и он готов к записи.
- **Зрение.** OBS захватывает только окно Minecraft, агент сам делает скриншот и описывает, что видит.
- **Стабильный цикл.** «Слышу → понимаю → отвечаю»: не отвечает на эхо своих сообщений и на служебные строки сервера, выдерживает 6 с паузы против антиспама, не молчит из-за пустых ответов модели.
- **Тихий мод.** Alto Clef больше не засыпает чат служебными сообщениями.

Сделано заранее: зрение (план занятия 5), голос через виртуальный кабель (основа для голосового чата, занятие 5), OBS для записи бесед (занятия 7–8).

## 31.10.2026

- **Тишина после ~40 сообщений.** При обрезке истории в начале мог остаться ответ инструмента без вызова (`ToolMessage`). Mistral отвечал 400 `Unexpected role 'tool' after role 'user'`, и агент замолкал до перезапуска. Теперь история после обрезки начинается с ближайшего сообщения игрока (`src/agent/multi/chat_agent.py`, `_trim_prefix_if_needed`).
- **Удары по себе.** Агент и игрок пока на одном аккаунте, и свой ник агент видит как игрока «в 0 м, можно атаковать». Он отдавал `@strike` по себе. Теперь `agent_action` не выполняет `pursue`/`punk` по своему нику (`src/agent/tools/minecraft_tools.py`).
- **Fish TTS нативно на Mac (M4, 16 ГБ, MPS).** Около 40 с на фразу (в Docker было 160 с). Для живой игры медленно, остаётся для записей или арендованной видеокарты. Клиент `src/tts/fish/fish_gr.py` шлёт `temperature=0.4`, а Fish 1.5.1 принимает минимум 0.6. Пока не исправлено.
- Агент проверен на публичном сервере: видит игроков рядом и отвечает им в чате.

### Известные проблемы

- Отдельного игрового аккаунта нет. Эхо своих сообщений отсекается, но агент путает себя с создателем.
- Латинские ники в исходящем чате портятся (`arcmlchikkk` → `arcmlкхиккк`).
- Отвечает на вопросы, адресованные другим персонажам («Зевс, расскажи…»).
- Практические факты иногда выдумывает (состав фейерверков).
- RAG не стартует: нужны локальные эмбеддинги (`bge-m3` через LM Studio на `:22227`). Это задача занятия 4.
- Живым голосом не проверено, нужен второй игрок в голосовом чате.
